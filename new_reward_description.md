Алгоритм МО, основанный на PPO, предназначен для построения башни из блоков в симуляторе MuJoCo. Изначально все блоки лежат на земле в случайных местах.
Для алгоритма МО с подкреплением была придумана награда, действующая в зависимости от текущего состояния башни:
1) первым выбирается Текущий блок, ближайший к Точке Притяжения (далее ТП) - координате (0, 0, 0). Координаты в формате (x, y, z)
Для этого Текущего блока награда определяется дальностью от точки притяжение относительно предыдущей позиции. Для Текущего блока награда = (перемещение относительно предыдущей координаты) * коэффициент сближения
2) когда Текущий блок приблизился к ТП на расстояние < 0.5 ширина блока, выбирается следующий Текущий блок и следующая Точка Притяжения
3) новой ТП становится координата верхней поверхности Текущего Блока + 0.5 * высота блока
4) новым Текущим блоком выбирается блок, ближайший к Текущему блоку
